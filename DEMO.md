# Demonstration script

Open the local app at http://127.0.0.1:8877.
Start on Overview and explain the question: when AI works as a team, what evidence supports its story?
The four source collections provide records. Their combined count is not a count of agents.

Select Trace a real example.
Open the scanner record, then both wiki revisions.
Show the preserved URL in the later revision and its added lines.
Explain that another appearance does not automatically establish another exchange.
Open Activity patterns to see how busy periods can direct a review. A peak alone is not proof of coordination.
When saving a review, record a next action and how it will be checked. Update the response in Saved reviews.

Select the records and save a review.
Leave operator independence, model identity, and permission unknown where evidence is missing.
Export the review to show that conclusions retain source IDs.
The exported report excludes raw transcripts.

Open Measure cooperation.
Explain that the example uses invented scores and equal recorded budgets.
Show why communication costs count and why a higher score does not prove superlinear scaling.
Import actual recorded results to use the same calculation on real experiments.

Open Compare words and actions, then Test detection.
Explain the difference between a convincing-sounding message and an observed action.
Show the difference between random and selective attempts at the same attempt count.
State that the synthetic example demonstrates the method rather than real detector performance.

End with the experiment plans and source library.
The app turns broad questions into controlled comparisons and keeps missing evidence visible.
The first release supports local analysis. It does not launch autonomous swarms or make paid model calls.
